# nodebb-plugin-sub2api-sso

Sub2API NodeBB SSO + wallet sync plugin.

## API Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| /api/sub2api/webhook | POST | Receive main platform webhook |
| /api/sub2api/forum-payment-callback | POST | Forum order payment callback |
| /api/sub2api/create-order | POST | Create forum order |
| /api/sub2api/wallet | GET | Query user balance |
| /api/sub2api/health | GET | Health check |
